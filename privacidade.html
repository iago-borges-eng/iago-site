Política de Privacidade ·

Aplicativo iago-os · Vigência: 21 de agosto de 2026

O iago-os é um painel pessoal de produtividade e vida, de uso individual, desenvolvido e mantido por Iago Borges. Esta política explica quais dados o app acessa, como usa e protege — em especial os dados obtidos via APIs do Google.

Dados que acessamos

  • Google Agenda (Calendar) — somente leitura: títulos, horários, local e participantes dos seus eventos, para exibir sua agenda dentro do seu painel.
  • Google Gmail — somente leitura (quando você ativar): metadados e conteúdo de mensagens, para montar um resumo do seu dia. Enquanto não ativado, não é acessado.
  • Identificação básica: seu e-mail e nome da conta Google, apenas para vincular a conexão.

Como usamos

  • Os dados são usados exclusivamente para exibir e organizar sua própria informação dentro do seu painel iago-os.
  • São armazenados no seu banco de dados privado (Supabase), protegido por regras de acesso por usuário (RLS) — só você acessa.
  • Não vendemos, não compartilhamos e não usamos seus dados para publicidade nem os transferimos a terceiros.
  • Nenhum dado é usado para treinar modelos de IA.

Uso Limitado (Google API Services)

O uso das informações recebidas das APIs do Google pelo iago-os adere à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

Retenção e exclusão

Os dados ficam no seu banco enquanto a conexão existir. Você pode revogar o acesso a qualquer momento em myaccount.google.com/permissions, e solicitar a exclusão dos dados sincronizados entrando em contato.
